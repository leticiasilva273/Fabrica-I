# Wireframes

Índice dos wireframes de média fidelidade do Hospedagem Familiar (Fábrica de Software I). Cada pasta tem um README com a tabela de telas, caso de uso e requisito funcional.

| Perfil | Pasta | Telas (SVG) | Formato |
|---|---|---|---|
| cliente | [cliente/](cliente/) | 16 | 1024x640 desktop |
| proprietario | [proprietario/](proprietario/) | 6 | 1024x640 desktop |

Convenção: telas numeradas na ordem do fluxo (T-CLI, T-PRO), cinza com um único acento azul, ação principal em botão azul preenchido e ao menos um estado de exceção por perfil. Textos entre colchetes, como `[ valor ]` e `[ IMG ]`, são marcadores a trocar pelos dados reais.
